## 四、注释（本项目核心）

原书的注释是**页内同文件双向锚点**，没有一条跨文件：

```html
<!-- 正文侧：角标 -->
<a class="zy" href="#id1a" id="id1">〔1〕</a>

<!-- 注释侧：章末注释区 -->
<p class="zs"><a class="hl" href="#id1" id="id1a">〔1〕</a>国家主义派指中国青年党……</p>
```

| 指标 | 数值 |
|---|---|
| 正文注释角标（`a.zy`） | **2653** |
| 章末注释锚点（`a.hl`） | **2655** |
| 含注释的章节 | 381 / 416 |
| 跨文件注释 | **0** |
| 能取到注文 | **2646** |
| 原书注文缺失 | **7** |
| 同一注释号有多条注 | **2** |

### 4.1 零跨文件 —— 这是最好的情况

因为注文和引用在同一个 XHTML 里，弹窗可以**直接从当前已渲染的 DOM 取注文**：
不需要跳转、不需要换页、不需要滚动，**阅读位置绝对不会丢**。
原书 2653 个角标的响应是瞬时的。

### 4.2 原书自身缺失的 7 处注释

这 7 处**不是解析问题，是原书漏排** —— 正文引用了角标，注释区里根本没有对应条目：

| 文件 | 缺失的注释号 |
|---|---|
| `Section0427.xhtml` | `*`（愚公移山） |
| `Section0610.xhtml` | 〔3〕 |
| `Section0650.xhtml` | 〔6〕、〔7〕 |
| `Section0820.xhtml` | 〔23〕 |
| `Section0838.xhtml` | 〔5〕、〔6〕 |

**阅读器的处理**：点击这 7 个角标，弹窗会明说
> 原书此处没有对应的注释条目。正文引用了〔6〕，但注释区中没有这一条 —— 这是原书本身的遗漏，不是阅读器的问题。

而不是跳到页面底部把阅读位置搞丢。

### 4.3 原书把同一个注释号写了两条注（2 处）

| 文件 | 注释号 | 两条注文 |
|---|---|---|
| `Section0820.xhtml` | 〔22〕 | ① 四类干部的划分　② 刘建勋，时任河南省委第一书记 |
| `Section0838.xhtml` | 〔3〕 | ① 张本，原中科院革命委员会主任　② 十条，指前十条 |

**阅读器的处理**：弹窗把两条注文都列出来并编号，标题显示"共 2 条"，不丢内容。

### 4.4 其他已知瑕疵（不影响使用）

- **33 处重复 id**：其中 31 处是 `<title>` 里把正文 HTML 转义后又写了一遍（阅读器只取 `body`，天然不冲突）；另有 2 处是同一个角标在正文中被引用多次（如 `Section0323` 的〔34〕被引 3 次），跳回时定位到第一次出现的位置，符合直觉。
- 全角空格（`\u3000`）大量出现在注释区排版中，阅读器已做归一化。
